# SafKit

UI-библиотека React + TypeScript для проекта SafDev.
Имя npm-пакета: `@dalerjig/safkit`.

## Происхождение

Основа проекта — библиотека ShKit команды Shtab, использованная с разрешения компании.
В этом репозитории развивается её личная адаптация для SafDev.
Названия компонентов, включая `ShKitProvider`, и исходный `Changelog.MD` сохранены.
Отдельного файла лицензии в предоставленном архиве не было; новая лицензия при переносе не назначалась.

## Локальная разработка

Проверенная версия Node.js: 20.19.5. Команды выполняются из корня SafKit.

```bash
npm ci
npm run dev
```

Для доступа к dev-серверу через сетевые интерфейсы WSL:

```bash
npm run dev -- --host
```

## Проверка и сборка

```bash
npm run validate
npm run build_with_check
```

Сборка библиотеки и декларации TypeScript записываются в `dist/`.
`npm run preview` предназначен для просмотра содержимого сборки; текущая library-сборка
не создаёт отдельный сайт документации.

## Подключение в SafDev

Пакет пока не опубликован в npm. После сборки можно создать локальный архив:

```bash
npm pack --dry-run
npm pack
```

Установите полученный `.tgz` в `SafDev/Frontend`, указав путь к архиву.
После установки:

```tsx
import { Button, ShKitProvider } from "@dalerjig/safkit";
```

React и React DOM передаются приложением-потребителем через `peerDependencies`.

## Task

При установленном Task доступны локальные команды:

```bash
task package:check
task package:build
task package:pack
```

`package:pack` проверяет состав архива без его создания и публикации.
Задачи доступа к прежнему registry и облачного деплоя удалены.

## Зависимости

По последнему отчёту `npm audit` остаются 5 предупреждений в цепочках
Vite/esbuild, vite-plugin-checker/picomatch и xlsx. Они ещё не устранены.
Проверки TypeScript и сборка не заменяют аудит зависимостей.
